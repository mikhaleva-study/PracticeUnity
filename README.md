Учебный проект, выполненный в рамках производственной практики.

- управление персонажем;
- слежение камеры с использованием Cinemachine;
- анимация бонуса через Animator и машину состояний;
- сбор монет;
- кошелек и отображение количества монет;
- система здоровья игрока;
- подвижное препятствие, наносящее урон;
- бочка со взрывчаткой, уничтожающая игрока при столкновении;
- перезапуск сцены после смерти игрока;
- система частиц при движении персонажа.
